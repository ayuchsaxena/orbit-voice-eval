# Contributor Covenant Code of Conduct

We are committed to a welcoming, respectful community. Be kind, assume good intent, give actionable feedback, and focus criticism on ideas and work. Harassment, discrimination, intimidation, personal attacks, and sharing private information without permission are not acceptable.

Project maintainers may remove, edit, or reject contributions that violate this code and may take other appropriate action. Report concerns privately to the repository maintainers.
